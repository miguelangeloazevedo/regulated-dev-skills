# Worked example: a review snapshot with missing effectiveness

Fictional package-planning exercise. There is no real export, clinical review, signature or product test result.

A review snapshot lists a freshness-control requirement, its design, a planned system case, a risk-control worksheet and a pending user evaluation. The snapshot cannot call the control verified merely because all five entries have links. Implementation execution and user-facing effectiveness are both still open.

The generated index should identify each controlled revision and label planned versus observed evidence. If the source set includes a revised requirement but the export still contains its predecessor, reconciliation raises a mismatch; changing the PDF title is not a correction. Regenerate from the source.

The package owner lists the clinical evaluation and other required external documentation by reference and responsible owner. A missing report is a gap, not text for the agent to invent. QA/RA confirms the relevant route-specific completeness review.

Only an actual export/open check can produce an observed readability result. None was executed for this fictional snapshot. At evidence levels below 3 the package keeps the repository's uncontrolled-draft label; `/release` cannot turn this example into a real authorised release.
